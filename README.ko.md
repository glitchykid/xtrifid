# Xtrifid

만들고 싶은 물체를 글로 설명하고 GTK 화면에서 메시를 보며 원하는 부품을 수정할 수 있습니다. 로컬 언어 모델이 부품 구성을 정하고 형상 엔진이 미터 단위로 메시를 만듭니다. 화면 언어는 러시아어입니다.

## Linux에서 실행하기

Docker Engine과 Compose, Git, `xauth`, OpenGL 3.3을 지원하는 X11 또는 XWayland 데스크톱이 필요합니다. Mesa 소프트웨어 렌더링도 사용할 수 있습니다. 처음 실행하면 컨테이너와 약 3.3 GB의 Qwen 가중치를 다운로드합니다. 메모리 16 GB의 CPU 환경에서 검증했습니다.

```sh
git clone https://github.com/glitchykid/xtrifid.git
cd xtrifid
./studio
```

스크립트가 Ollama를 시작하고 `qwen3.5:4b`를 받아 스튜디오를 엽니다. 다음부터는 Docker 볼륨에 저장한 가중치를 사용합니다. 입력한 설명은 로컬 Docker 네트워크에서 처리합니다. 구조화된 출력을 지원하는 다른 Ollama 모델을 쓰려면 `./studio` 실행 전에 `XTRIFID_MODEL`을 설정하세요. 서비스를 종료할 때는 `docker compose down`을 실행하세요.

## 모델 생성과 수정

1. **Описание модели**에 “가로와 세로가 각각 40 cm이고 두께가 4 cm인 좌판에 높이 40 cm인 다리 네 개를 모서리마다 단 스툴”을 입력하세요. 프로필을 고른 뒤 **Создать модель**을 누르세요.
2. 드래그하면 회전하고 휠로 확대하거나 축소합니다. 화면에서 부품을 클릭하거나 **Детали** 목록에서 선택하세요. **Сетка**를 누르면 폴리곤의 모서리가 보입니다. 뷰포트에 포커스가 있을 때는 방향키로 회전하고 +/−로 확대·축소하며 Home으로 모델 전체를 볼 수 있습니다.
3. “좌판 두께만 8 cm로 바꿔 줘”를 입력한 다음 **Изменить деталь**을 누르세요. 치수, 중심 좌표, 회전각을 XYZ별로 직접 입력할 때는 **Применить значения**를 누르세요. **Отменить действие**으로 직전 상태를 복원합니다.
4. **Сохранить**는 편집 가능한 `.xtri`를 저장하고 **Открыть**는 저장한 프로젝트를 엽니다. **Экспорт OBJ**는 현재 메시를 내보냅니다. 대화상자에서 `/exports`에 저장하면 호스트의 `./exports` 폴더에서 파일을 찾을 수 있습니다.

## 메시 프로필

| 프로필 | 메시 |
| --- | --- |
| Game Ready | 정점 순서가 일관적인 삼각형 메시입니다. 원주는 16분할이며 직육면체는 정점 8개와 삼각형 12개로 구성됩니다. |
| Для рендера | 원주를 48분할하고 곡면의 사각형 띠와 직육면체의 평면을 유지합니다. 극점과 복잡한 끝면에는 삼각형을 사용합니다. |

장면 하나에 이름이 있는 입체를 최대 48개 배치할 수 있습니다. 직육면체, 타원체, 원기둥, 내경을 지정하는 관, 원뿔, 토러스, 윤곽선 돌출, 단면 회전을 지원합니다. 벽의 단면을 회전해 속이 빈 용기를 만들 수 있습니다. 부품마다 독립적인 메시가 있으며 서로 닿거나 교차할 수 있습니다. 현재 버전은 정적 소품과 단단한 부품으로 이루어진 조립체를 대상으로 합니다. 캐릭터 변형용 리토폴로지, UV, 텍스처, 재질, 리깅은 지원 범위 밖입니다.

## 문제 해결

- **창이 열리지 않을 때.** 그래픽 세션의 터미널에서 실행하고 `echo "$DISPLAY"`와 `xauth info`를 확인하세요. 스크립트가 현재 디스플레이의 인증 쿠키를 전달합니다.
- **Ollama 오류가 발생하거나 첫 응답이 느릴 때.** `docker compose logs --tail 40 ollama`와 `docker compose exec ollama ollama list`를 확인하세요. CPU에서 모델을 처음 불러올 때 시간이 걸립니다. 요청이 실패해도 이전 장면은 유지됩니다.
- **원하는 형상이 나오지 않을 때.** 수량, 단위, 접촉 위치를 명시하세요. 윤곽과 메시를 확인한 뒤 해당 부품을 골라 수정하세요.

문제를 제보할 때는 입력 문장, 프로필, 재현 절차를 함께 적어 주세요. [GitHub Issues](https://github.com/glitchykid/xtrifid/issues) · [설계 및 Docker 테스트](docs/architecture.md)
